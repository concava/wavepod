# Security policy

## Supported versions

Only the latest release gets security fixes. Download it from
[GitHub Releases](https://github.com/concava/wavepod/releases/latest) or [wavepod.co](https://wavepod.co).

## Report a vulnerability

Do not open a public issue for a security problem. Report it privately:

1. Go to the [Security tab](https://github.com/concava/wavepod/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it and the version you used.

We reply within seven days. When the fix is released, we credit you in the release notes, unless you ask us not to.

## What counts

For example:

- audio, transcripts or questions that leave the Mac without the user's choice,
- a way to read the ChatGPT or Claude sign-in that Wavepod stores in the Keychain,
- code that runs from a podcast feed, a link or a downloaded file,
- a problem with how Wavepod checks or installs updates and models.
